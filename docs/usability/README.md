# Usability evidence (P16)

Templates for the A/B benchmark and the SUS survey. Jagpreet runs the sessions; results go into [`results.md`](results.md) and the README.

| File | Use |
|---|---|
| [`consent.md`](consent.md) | Read out and record consent before each session |
| [`tasks.md`](tasks.md) | Moderator script: the tasks, the A/B conditions, what to time and count |
| [`sus.md`](sus.md) | System Usability Scale questionnaire, with the scoring rule |
| [`results.md`](results.md) | Per-participant table, A/B summary and SUS summary |

Rules: use only the fictional PayWise data, record no names (participants are P1, P2…), and don't store recordings in the repo.
